# Extra 01 — Exam Grade Table

| File                                      | Description                                                                                                                                |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `extra01_exam_grade_table.r`              | Main script. Produces a grouped summary table of avg exam scores, avg final grades, and n per GPA range × extensions cell. Exports to CSV. |
| `raw_extra01_exam_grade_table.r`          | Prints the exact values and marginal totals shown in the table.                                                                            |
| `Edited_GPA_Extension_Analysis_table.csv` | CSV export of the summary table.                                                                                                           |
| `extra01_notes.typ`                       | Typst document — purpose, output description, raw values, stats, interpretation.                                                           |
| `extra01_notes.pdf`                       | Compiled PDF of `extra01_notes.typ`.                                                                                                       |
