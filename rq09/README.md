# RQ09 — Achievement Gap

| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `rq09_achievement_gap.r`      | Main analysis script. Produces two graphs: extensions by GPA (bar chart) and final grades by GPA (boxplot). Runs a Spearman correlation. |
| `raw_rq09_achievement_gap.r`  | Prints the exact x/y values and n counts shown in the graph.                                                                         |
| `rq09_graph1.png`             | Exported graph 1 — bar chart of extensions by GPA.                                                                                   |
| `rq09_graph2.png`             | Exported graph 2 — boxplot of final grades by GPA.                                                                                   |
| `rq09_notes.typ`              | Typst document — research question, hypothesis, both graphs, raw values, stats, conclusion.                                          |
| `rq09_notes.pdf`              | Compiled PDF of `rq09_notes.typ`.                                                                                                    |
